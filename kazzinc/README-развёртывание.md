# РАЗДАЧА · benevsky.work/kazzinc

Содержимое этого архива — готовая статика. Собирать на сервере нечего: выложить как есть.

---

## Куда класть

Всё содержимое архива (кроме этого файла) — в каталог `kazzinc` в корне сайта, чтобы получилось так:

```
benevsky.work/kazzinc/index.html          полная версия
benevsky.work/kazzinc/print.html          выжимка на одну страницу
benevsky.work/kazzinc/kp-ai-operations-director.pdf   книга, 27 полос
benevsky.work/kazzinc/og.png              карточка ссылки
benevsky.work/kazzinc/assets/…            скрипты, стили, шрифты, изображения
```

Сборка собрана под базовый путь `/kazzinc/` — он зашит в пути к скриптам и стилям. Каталог переименовать без пересборки нельзя.

## Три настройки на стороне сервера

### 1. Редирект на слэш — обязательно

`benevsky.work/kazzinc` → `benevsky.work/kazzinc/`

Ссылки между страницами и на книгу относительные. Без слэша на конце браузер отсчитает их от корня домена и получит 404 на `/print.html` и на PDF. Ссылку клиенту всё равно отправляйте со слэшем, но редирект защитит от того, что его случайно отрежут при копировании.

### 2. PDF закрыть от индексации отдельно

В обеих HTML-страницах стоит `<meta name="robots" content="noindex, nofollow, noarchive">`. На PDF метатег не действует — файл индексируется сам по себе. Нужен HTTP-заголовок:

```
X-Robots-Tag: noindex, noarchive
```

на `*.pdf` в каталоге `kazzinc`.

**Про robots.txt.** В архиве он есть, но краулеры читают его только в корне домена. Файл `/kazzinc/robots.txt` не работает. Класть его в корень **не нужно**: он написан как `Disallow: /` и закроет от поиска весь benevsky.work.

### 3. Заголовки кеша

Имена файлов в `assets/` без хэшей — так задумано, папка раздаётся целиком. Поэтому вечный кеш не годится:

| Что | Cache-Control |
|:--|:--|
| `index.html`, `print.html` | `no-cache` |
| `assets/*`, `og.png`, PDF | `public, max-age=86400` |

При обновлении документа меняется содержимое файлов, а не имена — сутки достаточно, чтобы правка дошла до тех, кто уже открывал ссылку.

## Проверка после выкладки

1. `benevsky.work/kazzinc/` открывается, шрифты подхватились, изображения на месте
2. `benevsky.work/kazzinc` (без слэша) — редиректит, а не отдаёт голый HTML без стилей
3. В шапке работают обе ссылки: «книга · pdf» и «выжимка»
4. PDF открывается прямой ссылкой и весит около 3 МБ
5. Ссылка, вставленная в мессенджер, показывает карточку без слова «Helios»
6. `curl -I` на PDF отдаёт `X-Robots-Tag`

---

## Если адрес изменится

Базовый путь меняется одной переменной при сборке:

```
BASE_PATH=/новый-путь/ npm run build
```

Плюс адреса `og:url` и `og:image` в `index.html` и `print.html` — они абсолютные, потому что карточки ссылок относительных путей не понимают.
