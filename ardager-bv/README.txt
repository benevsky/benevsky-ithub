ПУБЛИКАЦИЯ · КП ARDAGER · Computer Vision и контроль поголовья
================================================================

ЦЕЛЕВОЙ АДРЕС
    https://benevsky.work/ardager-bv
    Именно на него ведёт QR-код в PDF и на странице подписей.


ЧТО В АРХИВЕ
    index.html        веб-версия предложения. Полностью самодостаточна:
                      шрифты, схемы и QR встроены в файл. Внешних запросов
                      не делает — работает и без интернета.
    kp-ardager.pdf    печатная версия, 22 полосы. На неё ведёт кнопка
                      «Скачать PDF» в подвале боковой колонки.


КАК ПУБЛИКОВАТЬ
    Положить оба файла в папку, которая отдаётся по адресу /ardager-bv/.
    Никакой сборки, сервера приложений и базы не нужно — это статика.

    Nginx:
        location /ardager-bv/ {
            alias /var/www/ardager-bv/;
            index index.html;
        }

    Любой статический хостинг (Cloudflare Pages, Netlify, GitHub Pages,
    S3 + CDN): просто загрузить содержимое папки.

    Важно: имя kp-ardager.pdf менять нельзя — на него ссылается кнопка
    скачивания внутри index.html. Если PDF выкладывать не нужно, кнопка
    даст 404; в этом случае удалите из index.html строку со ссылкой
    href="kp-ardager.pdf".


ЕСЛИ КНОПКА «СКАЧАТЬ PDF» НЕ РАБОТАЕТ
    Причина почти всегда одна — адрес без завершающего слэша.

    Открыто https://benevsky.work/ardager-bv   (без слэша)
        браузер считает текущей папкой корень сайта и ищет PDF
        по адресу https://benevsky.work/kp-ardager.pdf — мимо папки.

    Открыто https://benevsky.work/ardager-bv/  (со слэшем)
        ищет https://benevsky.work/ardager-bv/kp-ardager.pdf — верно.

    В index.html встроена подстраховка: если страница открыта без слэша,
    скрипт сам достраивает путь к PDF. Но правильнее починить на сервере —
    иначе та же ловушка сработает на любой будущей относительной ссылке.

    Nginx, редирект на канонический адрес со слэшем:
        location = /ardager-bv { return 301 /ardager-bv/; }

    Проверка: открыть https://benevsky.work/ardager-bv/kp-ardager.pdf
    напрямую. Если файл не открывается — значит он просто не залит
    в папку, и дело не в ссылке.


ДОСТУП И ИНДЕКСАЦИЯ
    В index.html прописано:
        <meta name="robots" content="noindex, nofollow, noarchive">
        <meta name="referrer" content="no-referrer">
    Страница не попадёт в поисковую выдачу. Это служебный документ,
    доступ по прямой ссылке.

    Если нужен более строгий режим — закройте папку базовой авторизацией
    на стороне сервера. Внутри файла защиты нет и быть не может.


ЧТО ПРОВЕРЕНО
    · внешних ссылок на файлы — нет
    · url() вне data: — нет
    · @import — нет
    · сетевых вызовов в JS (fetch, XHR, WebSocket) — нет
    · шрифты встроены base64, пять начертаний, полная кириллица
    · разметка валидна, незакрытых тегов нет
    · печать из браузера работает: боковая колонка скрывается,
      схемы и таблицы не рвутся


ОБНОВЛЕНИЕ
    Исходники и сборщики лежат рядом с этой папкой:
        web/kp-ardager-web.src.html   исходник веб-версии
        web/build-web.py              сборка: шрифты, QR, обёртки таблиц
        kp-ardager-v2.html            исходник печатной версии
        ../../benevsky-kp-system/     дизайн-система и сборщик PDF

    Пересборка веба:   cd web && python3 build-web.py
    Пересборка PDF:    python3 ../../benevsky-kp-system/build/build.py \
                           kp-ardager-v2.html КП_ARDAGER_CV_Восток_Бройлер_v2.pdf

    Адрес QR задаётся в двух местах — переменной QR_URL:
        web/build-web.py
        ../../benevsky-kp-system/build/build.py


ЗАМЕЧАНИЕ О СХЕМАХ
    Схемы существуют в двух комплектах и это сделано намеренно:
    в вебе — нативная HTML-вёрстка, вертикальная, без горизонтальной
    прокрутки на телефоне; в PDF — горизонтальные SVG, они лучше ложатся
    в полосу A4. Содержание и все цифры в обеих версиях идентичны.
